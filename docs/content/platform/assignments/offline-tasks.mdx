# Offline / in-person tasks

The `CUSTOM` task type (dashboard label **Offline task**) covers work completed
outside the browser: an in-person exercise, a presentation, a paper submission
that the teacher reviews later.

- Create it from the assignment editor → **Add task** → **Offline task**.
- The teacher can put instructions in the task description or the task editor's
  instructions field.
- The learner sees the instructions and a free-text response box; the response is
  auto-saved like any other answer.
- The task is not auto-gradable. The teacher grades it manually from the
  submissions/grading view; the response, score and feedback are stored on the
  normal task submission.
- A `CUSTOM`/`OTHER` task anywhere in an assignment disables auto-grading for
  that assignment, exactly like a file-upload task.
